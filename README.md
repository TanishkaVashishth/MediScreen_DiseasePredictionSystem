# MediScreen_DiseasePredictionSystem
A machine learning–based Disease Prediction System that estimates the risk of Diabetes, Heart Disease, Kidney Disease, Liver Disease, and Breast Cancer using medical parameters. Built with Random Forest models, Python, and a Next.js + React interface. Provides risk levels, recommendations, and downloadable reports.
# 🩺 **Disease Prediction System**

*Machine Learning + Next.js Web Application*

This project is a **machine learning–based disease prediction system** that estimates the risk level of **Diabetes, Heart Disease, Kidney Disease, Liver Disease, and Breast Cancer** using user-entered medical data. The system uses **Random Forest models** trained on real-world medical datasets from the **UCI Machine Learning Repository**, and provides a **risk percentage**, **Low/Medium/High category**, **personalized suggestions**, and an option to **download a report**.

---

## ✨ **Features**

* Predicts 5 major diseases using medical parameters
* Real-time ML predictions via API
* Clean UI built with **Next.js + React + Tailwind CSS**
* **TXT report download** with results and recommendations
* Color-coded risk output for clarity

---

## 🧠 **Tech Stack**

**Frontend:** Next.js, React, Tailwind CSS  
**Backend / ML:** Python, NumPy, Pandas, Scikit-Learn, Pickle  
**Datasets:** UCI Machine Learning Repository
